수도권 재건축 현황

서울·경기·인천 아파트 재건축 사업장 –곳 · 데이터 갱신 – · 출처·원본 데이터

진행 단계
지표 조건 (용적률·건폐율·세대수 등)

조건에 맞는 사업장이 없습니다.

읽는 법

  • 현재 단계는 여러 공공 출처 중 가장 진전된 단계입니다. 출처별 단계는 상세 정보에서 볼 수 있습니다.
  • 계획 용적률·건폐율·층수는 정비계획상 신축 계획값, 기존 용적률은 현재 단지 값입니다(출처가 제공하는 경우만).
  • 대지지분 = 건축물대장의 대지면적 ÷ 세대수(단지 평균). 오래된 대장은 대지면적이 비어 있는 경우가 많아 일부 단지만 표시됩니다. 세대당 구역면적(구역면적 ÷ 기존 세대수)은 도로·공원이 포함될 수 있어 실제 대지지분보다 큰 참고치입니다.
  • 실거래가는 국토교통부 아파트 매매 실거래가(최근 12개월, 해제 거래 제외)를 지번·단지명으로 사업장에 연결한 값입니다. 평당가는 전용면적 기준(만원/3.3㎡)입니다. 준공된 사업장은 새 아파트의 거래입니다.
  • 노후계획도시(1기 신도시: 분당·일산·평촌·산본·중동) 단지는 특별정비구역으로 지정된 곳만 공공 데이터에 나오며, 구성 단지 목록이 없어 구역 이름으로만 표시됩니다.
  • 공공데이터를 자동으로 모은 자료로 실제와 다를 수 있습니다. 중요한 판단 전에는 해당 지자체·조합 자료를 확인하세요.
